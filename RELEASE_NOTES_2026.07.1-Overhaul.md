# 2026.07.1-Overhaul

A tuning update to BO7 V5. Nothing else in the library changed.

- BO7 V5: Full and Balanced retuned. Full now lifts footsteps with combat
  ducking off. Balanced keeps Full's footstep lift with combat control on,
  sitting between Full and Competitive.
- BO7 V5 target curve replaced: log-spaced points in place of the old linear
  2 Hz grid, with revised gains.
- Capped, Competitive and Immersive are unchanged.
- All other games and versions are unchanged.

## If you use BO7 V5

Re-run your squig.link EQ against the new target. The old EQ was generated
against the previous curve and will not match.

See [RELEASE_NOTES_2026.07-Overhaul.md](RELEASE_NOTES_2026.07-Overhaul.md) for
the 2026.07 release this builds on.
