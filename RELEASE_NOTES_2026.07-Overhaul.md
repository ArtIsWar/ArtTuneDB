# 2026.07-Overhaul

The largest release since ArtTuneDB launched. New virtual audio substrate,
new library format, 16-channel spatial audio, and a new install experience.

- Virtual cable: Hi-Fi Cable retired, replaced by VB-CABLE. Two render
  endpoints (Art Tune, 8ch and Art Tune +, 16ch) and one capture endpoint
  (Art Tune Unified Output). Custom device icons.
- Voicemeeter path unchanged. Both cables land in the same place.
- Pre-V5 tunes route to Art Tune. V5 and later route to Art Tune +.
- Anonymous setup counter added. Visible in install output, counts
  setups, nothing else.
